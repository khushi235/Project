## ✨ About the Project

Angel Star Inc. is a full-stack diamond jewelry platform designed to deliver a premium,
modern shopping experience while providing administrators with complete control over
the jewelry catalog.

The platform combines a visually focused customer storefront with a MongoDB-backed
admin management system.
